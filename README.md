# Estudando Python

Lista de exercícios de Python resolvida em aula do SESI SENAI no curso Técnico em Desenvolvimento de Sistemas.

## Tecnologias

- Python
- Visual Studio Code (VS Code)

## Exercícios

Os arquivos deste repositório abordam os seguintes tópicos:

- `bissexto.py`: verifica se um ano é bissexto.
- `compara.py`: compara dois números e identifica o maior ou se são iguais.
- `condicional.py` e `par_impar.py`: verifica se um número é par ou ímpar.
- `conversor.py`: converte temperatura de Celsius para Fahrenheit.
- `fatorial.py`: calcula o fatorial de um número.
- `for.py`: apresenta os números de 1 a 100.
- `maioridade.py`: verifica se uma pessoa é maior ou menor de idade.
- `media.py`: calcula a média de três números.
- `positivo_negativo.py`: identifica se um número é positivo, negativo ou zero.
- `soma.py`: calcula a soma de dois números inteiros.
- `triangulo.py`: verifica se três lados formam um triângulo e o classifica.

## Para testar

No terminal, navegue até a pasta do projeto e execute o arquivo desejado com Python:

```bash
python nome_arquivo.py
```

Por exemplo:

```bash
python soma.py
```
